# База кандидатов для квизов

`song-pool.json`, `song-pool-2.json` и `song-pool-3.json` — три тысячи пар «исполнитель — песня» для будущих выпусков. Это кандидаты, а не готовые карточки: YouTube-клип, фактический год релиза, форма исполнителя и границы фрагмента проверяются непосредственно при сборке квиза.

`chart-songs-spotify-ru.json` — отдельный каталог всех 2 967 уникальных записей из доступного агрегата дневного Spotify-чарта России за 2020-07-15…2022-04-07. Он включает и зарубежные песни: поле `isLocalCandidate` отмечает русскоязычные и локальные записи, пригодные для основной тематики квиза. Поле `alreadyInSongPool` позволяет отличить уже сохранённые пары.

`chart-songs-europa-plus.json` — 816 уникальных песен из 820 позиций ежегодных чартов «Европы Плюс» за 2007–2025 годы. Повторные попадания одной песни по годам объединяются и повышают `annualAppearanceWeight`. У 39 старых записей источник не указал исполнителя; они сохранены с `artist: null` и `artistResolution: "missing"`, чтобы не подставлять догадку вместо данных.

Первый файл сильнее ориентирован на новых для квиза исполнителей. Во втором повторы исполнителей разрешены, но песни не пересекаются ни с первым файлом, ни с уже сыгранными карточками.

## Как использовать

1. Загрузить все файлы `data/song-pool*.json`, затем исключить точные песни, уже присутствующие в актуальном `app/quiz-data.ts`.
2. Исключить карточки, помеченные пользователем как плохой фрагмент.
3. Взять смесь `sourceBand`: меньше очевидных `recognizable`, больше `middle` и `deep`.
4. Проверить название и исполнителя минимум по двум источникам.
5. Найти устойчивый официальный ролик и подобрать фрагмент без произнесённого названия песни.

`listYear` и `listRank` относятся к редакционной подборке Lezza TV и не считаются подтверждённым годом релиза или официальной позицией в чарте. `goldenGramophoneYears`, если поле есть, служит только дополнительным независимым сигналом узнаваемости.

## Чартовый вес

Третий пул строится из дневного агрегата Spotify Russia. Дневной и недельный агрегаты одного чарта намеренно не складываются, чтобы не учитывать одно и то же попадание дважды.

`chartScore` приведён к шкале 0–100:

- 40% — логарифм числа дней в чарте;
- 25% — логарифм суммарных прослушиваний;
- 20% — доля дней в топ-10;
- 10% — сила пиковой позиции;
- 5% — доля дней на первом месте.

Сырые показатели (`appearancesDays`, `top10Days`, `numberOneDays`, `peakPosition`, `peakStreams`, `totalStreams`) сохраняются рядом, поэтому формулу можно менять без повторного ручного сбора.

## Источники

- [Lezza TV](https://www.youtube.com/@LEZZATV/videos) — основной широкий каталог ежегодных редакционных подборок.
- [Золотой граммофон](https://ru.wikipedia.org/wiki/Список_лауреатов_премии_«Золотой_граммофон») — независимая проверка части известных песен.
- [TopHit](https://tophit.com/chart/top/radio/hits/ru/annual) — ручная сверка радиочартов.
- [Песня года](https://ru.wikipedia.org/wiki/Песня_года) — дополнительный источник для старых и тематических выпусков.
- [Подборка музыкальных квизов](https://www.youtube.com/playlist?list=PL9vtHjwVXGU0syiRIYghW2A4_lT0UtaY1) — контроль ощущения сложности и узнаваемости.
- [Spotify Charts](https://charts.spotify.com/charts/overview/global) — исходный чарт; недельная методология описана в справке Spotify.
- [Kworb: Spotify Daily Chart — Russia](https://kworb.net/spotify/country/ru_daily_totals.html) — доступный агрегат повторных дневных попаданий за 2020–2022 годы.
- [Европа Плюс: ежегодные чарты](https://europaplus.ru/year-chart) — официальные годовые списки за 2007–2025 годы.

## Обновление чартового каталога

Сохранить HTML агрегата во временный файл и запустить:

```bash
node scripts/import-spotify-russia-chart.mjs /path/to/ru_daily_totals.html
```

Скрипт заново собирает `chart-songs-spotify-ru.json` и `song-pool-3.json`, исключает песни из первых двух пулов и текущих квизов и ограничивает одного нормализованного исполнителя двенадцатью позициями.

Для сохранённых JSON ежегодных чартов «Европы Плюс»:

```bash
node scripts/import-europa-plus-charts.mjs /path/to/year-json-directory
```
