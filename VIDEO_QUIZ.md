# Видеоквизы

Вторая вкладка главной страницы. Гостевая ссылка создаётся кнопкой «Пригласить гостя» и открывает `/g/video/<token>`.

## Правила

- В обычных раундах весь бланк фиксируется автоматически на границе приёма. Баллы и ключи появляются с началом показа ответов.
- В «Трёх шансах» один ответ на исполнителя отправляется только кнопкой. Несданный ответ даёт ноль. Шкала: 2 / 1 / 0,5.
- Исполнитель — 1; один из двух — 0,5; название песни — 0,5; единственное поле в «Плюс один» — 1. Максимум выпуска — 120.
- F2 приостанавливает видео для дописывания, в том числе внутри поля. Повторное нажатие продолжает. Пробел вводит пробел. Перемотка назад не открывает сданные ответы.
- Номера раундов позволяют перейти к выбранному раунду. Переход сохраняет введённое и закрывает пересечённые бланки; в «Трёх шансах» сам переход не отправляет ответ.
- Отдельные кнопки «Следующий вопрос» и «Следующий ответ» ведут к началу следующего вопроса или конкретного ответа в MP4. В «Трёх шансах» следующий вопрос — следующий исполнитель, а не следующая песня того же исполнителя.
- Видео крупнее и остаётся сверху при прокрутке. Активный вопрос плавно появляется под ним; во время ввода автопрокрутка не мешает печатать. Поля напоминают нужную форму ответа.
- Строки бланка компактные: форма указана только внутри поля, год и альбом в бланке не дублируются. При Tab и Shift+Tab поле автоматически остаётся ниже закреплённого видео. Правильный вариант и действия после раскрытия находятся в одной строке, когда ширины достаточно.
- При сетевой ошибке видео останавливается, черновики остаются в браузере. Доступно повторное сохранение.

Прохождения, гости, ответы, баллы, комментарии и история правок сохраняются в SQLite через `QUIZ_DB_PATH`. Гость узнаётся по HttpOnly-cookie этого браузера. После удаления cookie прежние результаты остаются у ведущего, но гость не может восстановить доступ по одному имени.

Ведущий может исправить баллы с готовой причиной «Исполнитель или название всё-таки верны» без комментария. Другая причина, аннулирование и жалобы требуют комментария. Лояльная проверка исполнителей принимает фамилии сольных артистов, транслит и опечатки; у групп фамилия не выделяется. Авторазбор комментариев пока работает по правилам классификации; внешний ИИ-бот и утренняя автоматизация к этим комментариям ещё не подключены. Авторазбор сам вопросы не аннулирует.

Для следующих роликов в конце обычного раунда предусмотрены 15 секунд на запись ответов. Текущий MP4 и его тайминги не меняются.

## Видео и выпуск

Ключи и тайминги хранятся только на сервере: `server/video-data/prosto-v3.json`. При начале прохождения сохраняется снимок правил выпуска. Изменённому видео нужно давать новый ID и имя файла, чтобы старые прохождения не получили другие тайминги.

В текущем MP4 осталась прежняя озвучка баллов «Трёх шансов» (3 / 2 / 1); сайт явно предупреждает о новой шкале. Бланки синхронизированы с фактическим монтажом. Желаемые 15 секунд музыки + 5 секунд сдачи, новые сложные подборки, менее заметные маски, отсутствие названия в вопросах и разнообразные непохожие каверы относятся к следующему монтажу. Замечания сохранены в `work/prosto-quiz-v3/user-feedback.md` и производственной спецификации.

## Публикация

MP4 не входит в Git. Перед публикацией кода загрузить его как `/var/tmp/music-quiz-upload/prosto-v3.mp4` на сервер. `deploy/update.sh` проверяет SHA-256 из `deploy/video-media.sha256`, устанавливает файл в `/opt/music-quiz/media` и лишь затем собирает и переключает приложение. При несовпадении или отсутствии файла работающая версия остаётся на месте. Для следующего выпуска добавить отдельный файл и его проверенную контрольную сумму.

Можно переопределить каталог переменной `VIDEO_QUIZ_MEDIA_DIR`. Локально доступен исходный файл `work/prosto-quiz-v3/output/Просто квиз — 8 раундов.mp4`. Каталог и ключи JSON включены в standalone-сборку, медиа обслуживается с поддержкой Range/HEAD.

Приватные `/api/video-*` защищены существующей авторизацией Nginx. Порт Next.js должен слушать только localhost; нельзя открывать эти API отдельным публичным location без авторизации. Гостевые маршруты проверяют ссылку и владельца прохождения. Это личная игра с паузой, а не защищённый от просмотра ответов турнир: полный MP4 технически доступен участвующему игроку.

```bash
npm run test:video
npm run build
npm run start
```

Тесты используют отдельную временную SQLite и не меняют результаты игроков.
